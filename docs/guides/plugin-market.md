# 插件市场与可选组件

入口：设置 → 插件管理 → 插件市场。普通模式可用，无需专家模式。即使尚未安装任何插件，也会显示可安装项目。

## 第一版的范围

目录随内核发布，插件源码直接从 GitHub 的固定提交下载。无需中心服务器、市场账号或额外订阅。更新目录需要更新内核；当前没有自动升级已安装插件、第三方自由上架或自动发布角色包的功能。

- 桌宠：下载源码、安装 npm 依赖并构建。首次可能下载数百 MB 的 Electron。
- QQ 桥：下载源码并把声明的 Python 依赖安装到当前后端解释器。QQ 账号和网关仍须单独配置。
- 联网搜索：`tools` 仓库尚未公开，目录会明确标记暂未开放；不会通过切换代理绕过仓库权限。
- 本地说话与听写：安装 ASR（语音转文字）、TTS（文字转声音）、识别模型与中文音色。无需独立显卡。
- QQ 语音转写：仅安装识别、音频转换和解码，不安装朗读音色。
- 在线朗读：安装 Edge TTS 运行库，仍需连接在线服务。
- 本地语义检索：安装约 100 MB 的模型，运行库可能占数 GB。不装仍可使用关键词检索；外部 Embedding API 是另一种可选配置，可能收费，效果取决于服务与模型。

安装前展示用途、体积和来源，并要求明确勾选同意。插件代码与依赖是可信本机代码，会运行安装／构建脚本，不是隔离沙盒。

## 安装过程

安装任务在后台执行，页面展示阶段和完成／失败状态；刷新页面后可以找回最近任务。当前只允许一个安装任务，安装中不应用插件开关、卸载或网页重启操作。

源码下载和构建先在临时目录完成，成功后才放入插件目录。已有目录不会覆盖。新装插件保持关闭，不自动启动桌宠、不连接 QQ、不调用模型。安装成功后重启后端，再在“已安装”启用并应用修改；前端源码插件在生产部署下还需重新构建前端。

可选组件写入后端虚拟环境和模型目录；`--inexact` 保留先前安装的可选包。组件失败不承诺回滚已安装的依赖；可以查看错误并重试，完整下载的模型会复用。不要在安装中关闭启动窗口。后端异常退出时，任务会标记中断而非成功。

日志仅保存在本机 `backend/data/plugin-installs/`。日志可能含本机路径、下载错误或供应商信息，分享前检查；网页不会直接返回完整日志。可选依赖当前不提供一键卸载，避免误删共享运行库。

## 网络方案与边界

默认直接使用 GitHub、包仓库与模型官方源，不安装 VPN，不购买服务，不自动改系统代理，也不自动切换第三方 GitHub 转发网站。用户已有的环境变量和 Git 网络设置继续生效。

免费且可选的后续方案是提供仅影响本应用的代理／模型镜像配置与连通性诊断，保存前显示地址和影响范围；不探测用户代理密码，不代替用户搭建网络环境。该配置界面尚未实现。

目前模型镜像可显式指定，例如在启动前设置你选择的可信镜像根地址：

```powershell
$env:HF_MIRROR='https://your-trusted-mirror.example'
$env:VOICE_MODEL_MIRROR='https://your-trusted-mirror.example'
& '.\启动 Shionarium.bat'
```

这些是占位地址，需要自行替换。镜像不等于代理，第三方可用性和下载内容需要自行核对；不能保证某台机器测试可达就对所有用户可用。语音本地处理不代表聊天模型也离线。仓库 404 还可能表示尚未公开或权限不足，不能一概当成网络问题。
