# 纸与墨 / Paper & Ink

这是不含角色和外部素材的原创外观包示例，采用 Apache-2.0。可复制并修改；请把 ID、名称与作者改为自己的，保留适用的许可声明。

在内核根目录运行：

```powershell
backend\.venv\Scripts\python.exe tools/build_appearance_pack.py examples/appearance-packs/paper-ink dist/paper-ink-1.0.0.zip
```

用户在“外观”中选择 ZIP、确认安装，再点击“应用外观”。接口与可选字体/背景说明见 `docs/guides/appearance-packs.md`。
